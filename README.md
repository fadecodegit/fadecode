# Proyecto Base de Datos (Proyecto_BD)

Este repositorio contiene la arquitectura de base de datos, scripts SQL de creación/población y documentación técnica asociada.

## 📁 Estructura del Repositorio

* `Scripts_SQL/`: Scripts de creación de tablas, triggers, procedimientos y datos iniciales.
* `Documentacion/`: Documentación técnica, requerimientos y especificaciones del sistema.
* `DiagramaMer/`: Diagramas Entidad-Relación (MER) y modelos relacionales.
